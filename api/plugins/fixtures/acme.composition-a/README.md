# Composition A fixture

Build this directory as a real `.1flowbasepkg` tar.gz archive. It binds two process-per-call contributions and one declarative owned collection under one installed identity. Grants are supplied exclusively by the host after workspace assignment. The two executable contributions deliberately require the same permission to detect module permission unions.

The Python worker reads the existing capability stdio protocol. An optional `fixture_barrier` path is used only by the acceptance fixture to observe admitted work without timing assumptions. Custom event declarations are added by P05; typed Hook execution is added by P03.

## Durable composition event variant

`event-manifest.yaml` is the Root AC-007 A publisher variant; the original manifest remains
the multi-contribution hook fixture. Package the variant as `manifest.yaml` with the prebuilt
`runtime-extension-sdk --example managed_event_worker` binary at `bin/worker.py`.
Grant `event.subscribe` and `event.publish` separately to `acme.composition-a.events`
(`managed-event@1`, workspace). Its `publish` handler emits only the sealed processed@1 payload.
The host records one stable derived E2 under A's current authorization lock; B/C's own event
contributions consume it with separate owned-write grants and atomic receipt/effect commits.
