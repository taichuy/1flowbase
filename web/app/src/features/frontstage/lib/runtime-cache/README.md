# Native React Artifact Cache

缓存只保存编译产物，后端仍是源码、授权及业务数据的唯一真值。每次打开先取得后端当前源码与贡献绑定，再按 actor、workspace、源码 SHA-256、compiler/runtime ABI 和模块定义指纹查找产物。

| 操作 | 编译与执行 |
| --- | --- |
| 调试“刷新区块” | 获取当前源码，跳过产物缓存与旧编译 flight，真实编译、重新求值、重建组件实例及独立模块/样式作用域 |
| 普通打开、浏览器刷新 | 获取当前源码与授权后复用匹配产物；浏览器刷新可从 IndexedDB 恢复，组件状态及业务结果重新建立 |

## Storage and Scheduling

- L1 使用直接依赖 `lru-cache@10.4.3` 的有字节上限 LRU。准入时复制、校验并冻结产物，命中只做哈希表查找及链表移动，摊还 `O(1)`；上限沿用 16MiB 产物预算。
- L2 分为 `records`（产物）、`metadata`（小型索引记录）与 `state`（预算、单调时钟、actor epoch）。命中只读取目标产物，校验成本随目标产物大小增长，与缓存条目总数无关。
- 按 Workbox 的元数据分离与合并维护方式，访问更新在显示路径外批处理；L2 最近访问顺序为异步近似，L1 保持严格 LRU。维护每批最多更新 32 个键，待更新键最多 128 个；覆盖同一键时保留最近访问顺序。待写产物按字节预算限制，覆盖或超限待写项可丢弃，因为产物可重建。
- 新增/替换、按访问索引淘汰和字节计数属于同一个 IndexedDB 事务。对产物记录序列化字节大小 `s_i`，提交完成时保持 `sum(s_i) <= B`；计数不含 IndexedDB 引擎和独立索引的存储开销。多个标签页写入共享事务作用域，避免各自算预算后同时超限。
- 删除 actor 与 workspace pruning 推进 epoch；任务在源码读取前捕获 epoch。旧任务与待写队列不能在清理后重新持久化旧分区。当前窗口同时失效 L1；另一个窗口仍需从后端获取最新源码与授权。
- IndexedDB V1 的旧编译记录在升级时直接清空，按需重建。此升级只涉及浏览器缓存。持久化失败不阻断渲染；IndexedDB 不可用时仍可复用当前文档中已验证的 L1。

浏览器编译服务最多复用两个 Worker，一次每个 Worker 处理一个编译任务。普通重复编译按完整作用域 identity 合并，每个调用者独立拥有取消；最后一个调用者取消或 Worker 故障时销毁该 Worker。调试刷新不参与 flight 合并。Worker 只做 transform 与校验，不执行组件代码。

Worker 编译无需等待主线程交互 lease；模块求值和挂载仍由页面准备调度器保护。显式刷新使用 user-visible 优先级并跳过自身点击造成的固定 lease，后台准备继续避让输入。

## Verification Boundary

行为测试覆盖缓存隔离、损坏回退、冻结、预算与事务回滚、跨连接旧 epoch、Worker 复用/取消/故障，以及调试刷新重新求值和独立模块作用域。性能采样使用当前本地静态构建、真实区块源码，分别记录调试刷新、SPA 重开与浏览器重载的挂载和业务数据时间。

500ms 目标针对区块准备/挂载；整个 document 启动以及业务接口完成时间需单独报告。测试与采样证据保存到 `tmp/test-governance/block-rendering/`，不将开发环境数值当作公网或所有设备保证。
