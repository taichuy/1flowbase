2026-10-31 用户确认：模板目录入口使用“安装”，点击后下载模板并在弹窗展示安装变更，确认时安装同一份已下载内容。取消单独的“预览安装”入口，不接受预览和确认分别重新下载模板的流程。

动机：消除重复下载与等待，确保用户确认的是已看到变更的模板内容。该决定持续有效，无预定截止日期；后续调整安装流程时先核对现有实现与本次用户要求，不恢复重复下载。
