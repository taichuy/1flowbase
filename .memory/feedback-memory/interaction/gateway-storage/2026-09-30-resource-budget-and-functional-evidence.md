title: 网关存储优化必须量化全资源成本且区分GUI证据阶段
date: 2026-09-30 08
feedback_category: interaction
decision_policy: direct_reference
---

规则：Gateway 存储优化须预先声明 CPU、内存、存储、网络 I/O、并发与稳定性指标；用同一完整事实与请求负载对照验证。行数下降、引用共享、局部 PG 成本下降不能替代全部资源目标。报告失败门槛，不事后放宽；区分原型、现有 GUI 基线、候选 GUI 以及整网关验收。说明时间/空间复杂度、隐藏索引/引用与回收成本，并用数学或简图解释取舍。

原因：用户指出此前方案缺少量化指标和预期，要求确认在正式应用 GUI 完整功能下 CPU、内存、存储与网络 I/O 确实减少，且网关方向向高并发、稳定性与存储目标收敛。局部收益外推或只计两张表会掩盖成本转移。

适用场景：1flowbase Gateway 轨迹、事件、上下文与归档的设计、优化实验和交付。内部 DB wire 与对外协议网络分开；已有功能/可靠性是硬约束，不能以截断、关闭记录或破坏分页换性能。
