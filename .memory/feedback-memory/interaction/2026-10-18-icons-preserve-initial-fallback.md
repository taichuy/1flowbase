- 规则：用户要求补齐采集器或插件图标时，优先复用本地源码或已安装应用的品牌 SVG；缺少资源时可绘制 SVG。保留缺失图标时的首字母兜底，不把兜底设计本身描述为错误。
- 原因：用户明确指出首字母是原有缺省设计；本轮要求补充正式图标，而不是取消兜底。
- 适用场景：为采集器、插件或同类入口补齐品牌图标，解释缺省显示与资源缺失的区别。
