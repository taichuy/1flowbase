## 规则

以 `/settings/model-providers/providers` 当前实现为参考，模型管理以主实例为单元；来源实例是主实例下的接入配置，不应平铺来源连接作为页面的管理主体。

- 2026-10-02 补充：复刻该页面到低代码区块时，按原页面核对每行操作和展示信息；不得擅自增加实例数量。每行需要保留「实例管理、新增、更新、卸载」及其真实交互，不能只留下查看实例按钮。
- 2026-10-02 补充：复刻每行操作时保留原页面的紧凑间距；不能只复制 `Space size` 而忽略原页面对链接按钮内边距的设置。用户指出四个按钮原本紧挨着，复刻后间距过大。
- 原因：用户指出先前复刻额外添加了数量，并遗漏每行新增、更新、卸载操作；要求恢复原页面。

## 原因

用户明确纠正了低代码页面平铺来源实例的做法。简化交互不能改变主实例聚合模型与来源实例的领域关系。

## 适用场景

模型接入低代码页面和下游应用分组选模；主实例聚合状态与路由以当前后端契约为准。
