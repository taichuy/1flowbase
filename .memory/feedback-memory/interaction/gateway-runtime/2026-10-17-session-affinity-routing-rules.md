## 规则

- 显式配置的分配、失败重试或轮询规则拥有相应选择行为；符合失败重试条件时，按规则切换下一个合法实例并重试，不能由默认会话粘性阻止规则执行。
- 分配规则为“无”时，识别并沿用会话发起实例；该实例请求失败时如实返回错误，不暗中切换、重新绑定到其他实例或将业务失败包装为成功。
- 撤回此前“默认软亲和，原实例不可用时可自动切换”的建议。跨实例重试的授权来自显式规则，不能因请求携带完整历史就自行开启。
- 三种协议（Responses、Anthropic Messages、Chat Completions）遵循一致的分配语义；该决定不重新开启已放弃的同协透传改造。

## 原因

用户要求运行行为与界面配置一致：设置为“无”应保持原实例及真实失败；主动开启规则才允许规则声明的自动调度，避免默认恢复逻辑覆盖用户意图。

## 适用场景

AI Gateway 会话亲和性、模型供应商分配、跨实例失败重试的方案、实现和验收。供应商专有续传状态仍需满足协议可执行条件；显式规则不代表可把某实例的私有游标直接发送给另一个实例。
