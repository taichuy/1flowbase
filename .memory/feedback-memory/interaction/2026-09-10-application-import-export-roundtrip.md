- 用户反馈：应用管理增加导入按钮后，四应用导出的 ZIP 预览失败，质疑为何只修改前端。
- 规则：复用导入能力前必须核对同页导出的单项/多项归档与后端预览、写入数量契约；入口接通及单项预览通过不等于导出→导入闭环成立。
- 原因：本次仅验证单应用文件、以 mock 预览成功覆盖 ZIP 选择，遗漏真实多应用归档，后端数量限制直接拒绝。
- 适用：新增导入、恢复、批量上传等入口及对应导出闭环的方案和验收；若后端契约不足，应在对齐阶段明确缺口，不能由前端临时解包拼接冒充后端能力。

- 2026-09-11 最新边界：用户决定保留既有路径唯一约束，导入冲突直接明确提示失败；不追加数字，不迁移为仅发布时检查。以最小修改补齐批量导入与逐项错误反馈。该决定覆盖此前草稿允许重复路径的提议。
