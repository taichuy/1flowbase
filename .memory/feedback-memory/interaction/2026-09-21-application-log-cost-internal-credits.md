title: 应用日志费用按内部积分直接累计
created_at: 2026-09-21 23
updated_at: 2026-09-21 23
feedback_category: product_semantics
decision_policy: direct_reference
---

规则：当前应用日志的费用是 1flowbase 自定义内部积分口径，后端直接累计金额，即使来源标有不同币种也相加；持久化使用可直接 SUM 的 numeric 字段，前端只展示单个数值。不要重新引入币种分组、换汇或 JSON 费用明细。

原因：用户明确纠正了上一版分币种 JSON 设计；当前阶段需要简洁、便于数据库统计的纯记录，不需要真实货币结算复杂度。

适用场景：应用任务日志的费用快照和统计。本决定不授权修改供应商价格配置或实际账务结算规则；若未来产品阶段改变，重新核对口径。

补充（2026-09-21 23）：用户要求当前前端在费用数字后固定显示 ` $`（数字与符号之间留一个空格），仅作阶段性展示；后端仍按内部积分直接累计，不恢复币种分组或换汇。
