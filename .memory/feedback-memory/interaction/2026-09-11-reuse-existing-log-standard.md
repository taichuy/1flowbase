# Reuse Existing Log Standard

- 规则：会话关联和聚合日志需求先复用原日志入口、汇总/消息/追踪投影及详情契约；不得把概念分层直接落成平行的 gateway 日志页签、接口、DTO 与表体系。
- 原因：用户明确否定 #2032 交付的“会话日志/原始运行日志”双入口及新增 gateway_log_* 体系，要求沿现有日志标准补齐跨调用关联。此前计划只说优先复用，未约束唯一入口和读模型，导致偏离。
- 适用场景：应用日志、网关会话聚合、模型运行追踪。必要关联字段/索引须说明原能力缺口；不能将单次运行聚合误称已支持跨运行任务，也不能因此新建第二套产品标准。移除已落库结构前明确数据保留与迁移影响。
