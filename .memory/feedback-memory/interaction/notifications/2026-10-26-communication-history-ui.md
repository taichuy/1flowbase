topic: 通讯会话管理复用表格与运行日志
summary: 会话和接收记录应默认显示可用记录、使用共享表格并显示状态与链接，页签/详情通过URL恢复；Agent-flow执行记录沿用三级日志，用run ID关联而非另建日志体系。
created_at: "2026-10-26 00"
updated_at: "2026-10-26 02"
decision_policy: direct_reference
---

- 规则：通讯中心的会话与接收记录参考发送日志交互，使用共享表格。渠道选择是可选筛选，不能成为看到记录的前提；列表显示后端状态，实体提供真实超链接，页签与已选详情应能通过 URL 刷新恢复。
- 规则：已绑定 Agent-flow 的执行记录复用现有三级日志体系，以运行 ID 查询并链接到现有日志 UI；不新增外键或复制一套执行日志。
- 原因：用户在真实使用中发现旧实现需要先选渠道、缺状态和链接、刷新丢页签；空态截图和组件测试没有覆盖有记录时的主路径。
- 适用：通讯中心历史/消息管理及类似管理列表验收。至少用有记录的页面检查状态、详情、链接与刷新，不以空态截图代表交互验收。
