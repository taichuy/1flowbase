- 规则（2026-10-26最新纠正，替代此前latest摘要/实体链接设计）：会话共享表格只展示基础渠道/聊天对象信息，不展示最新消息、时间及其状态聚合；操作列统一“聊天”打开实际复用的Agent-flow聊天组件。渠道选择是可选筛选，页签和聊天选择可通过URL恢复。
- 规则：会话与消息以会话ID查询，无外键耦合；文字、文件都是typed消息，文件行包含文件定位/访问路径。时间顺序展示，打开只取最新5条，按需加载更早记录。消息底部图标跳转原Agent-flow日志，附件须在聊天中可见。
- 规则：已绑定 Agent-flow 的执行记录复用现有三级日志体系，以运行 ID 查询并链接到现有日志 UI；不新增外键或复制一套执行日志。
- 原因：用户在真实使用中发现旧实现需要先选渠道、缺状态和链接、刷新丢页签；空态截图和组件测试没有覆盖有记录时的主路径。
- 适用：通讯中心历史/消息管理及类似管理列表验收。至少用有记录的页面检查状态、详情、链接与刷新，不以空态截图代表交互验收。

- 2026-10-26 用户再次明确纠正：通讯聊天必须复用运行详情完整浮窗外壳和聊天布局（同一标题栏、气泡、拖动缩放），点击聊天弹出无蒙层浮窗；只复用消息pane再套Drawer不满足要求。验收要对照用户截图核对整个壳和交互，不能用内部组件同名证明产品效果一致。
