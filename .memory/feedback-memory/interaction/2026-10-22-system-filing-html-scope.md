# 系统备案 HTML 保持简单

- 规则：本次系统设置的备案内容由管理员自由填写 HTML，原样保存并通过公开元数据读取，在登录页 Powered by 1flowbase 下展示；不加标签白名单、过滤、iframe 或独立编辑器。
- 原因：用户明确纠正此前受限 HTML 方案，目标只是简单的读取展示，不扩大实现复杂度。
- 适用场景：本次系统设置及登录页备案 HTML 需求；不泛化为其他用户内容的 HTML 策略。
