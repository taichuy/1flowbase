# 继续分析不等于进入计划

- 规则：用户要求“分析情况”并在后续说“继续”时，只继续取证和说明现状；不得擅自视为方向批准，不进入 Issue Tree、实施计划或产品修改。
- 原因：“继续”承接的是当前正在进行的分析语境，不会自动扩大用户授权。
- 适用场景：架构诊断、代码职责梳理、性能原因分析、组件现状调查及类似的连续追问。
