# 登录标语为开关，表单须验证视口内可达性

- 规则：本次系统设置中的登录左侧标语是显示/隐藏开关，不是自定义标题输入框；标题固定，用户已明确纠正此前可编辑标题的实现。
- 原因：用户要求的是开关，之前实现扩大为自由编辑，并漏掉受限视口内表单不可滚动的问题。
- 适用场景：系统设置与登录页标语控制；位于 viewport 容器的长表单验收需在较矮窗口中实际滚轮滚到保存按钮。完整页面截图不能单独证明用户能滚动操作。

- 2026-10-22 08 补充纠正：开关统一控制固定标题和固定标语；system_description 与此文字区无关，不能替换标语。设置表单应按最初参考图使用横向标签和铺满可用宽度的输入区，不能擅自改成纵向限宽布局。原因是此前再次误绑说明并偏离参考布局；适用于此系统品牌设置与登录展示。

- 2026-10-22 08 商业边界：用户明确登录左侧标题与大字的自定义属于商业化插件；开源后台对此区域仅提供统一显示/隐藏开关。审计时需检查表单、API 与间接 HTML 渲染入口，不能仅以没有编辑输入框判定无绕过。原因是需要保护开源底座与商业插件的职责边界；适用于登录品牌区后续扩展。
