- 规则：AI 助手是独立窗口，使用自己的配置和已发布应用；编排预览是当前页面的弹出组件，使用当前 applicationId 和当前编辑文档。两者复用内部展示，不合并容器、配置、会话或执行来源。
- 原因：用户纠正了把“共享组件”扩张为“统一入口或默认选择”的理解；URL 中有应用 ID 只用于当前编排上下文，不应覆盖助手配置。
- 适用场景：AI 助手、编排预览及其共用消息、输入、加载和结果组件的实现与重构。

- 后续纠正：用户要求提取 AI 助手完整 UI 与交互为共享前端插件，再替换旧预览；仅复用 DebugConsole、改背景或调整按钮位置不算完成。模型菜单、标题工具栏、输入底栏由插件统一实现，宿主只提供自己的配置、会话、执行与扩展操作。

- 最新确认：设置不共享时，预览隐藏设置入口；不得跳转开始节点。AI 助手保留原设置弹窗。

- 最新确认覆盖隐藏设置的决定：预览需测试现有 MCP 实例，因此恢复共享设置弹窗；预览固定当前应用，MCP 选择独立于助手偏好，并进入草稿运行及其恢复链路。不能只实现按钮或展示表单。
