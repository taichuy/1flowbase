- 规则：用户明确要求接口拥有统一生命周期，外部插件可按同一标准发现阶段、注册逻辑和参与执行；不能将当前仅接通 Create 的实施限制解释为目标架构应由各接口临时决定开放标准。
- 原因：逐接口特殊接线与不一致规则会妨碍外部插件通用适配。统一阶段和接入协议仍应保留宿主授权、数据契约、核心拒绝不可逆转与观察阶段不改主结果等已确认边界。
- 适用：后续插件开放方案、Wiki 和计划。分清目标、当前有限实现、统一规则下的成功/失败/取消分支；本条是方向纠正，不是实现或全接口发布授权。
