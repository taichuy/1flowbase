- 规则：用户要求参考现有项目一比一还原时，先列交互页面清单、真实界面截图、每张图对应的比对事项和相关代码，然后对照实现，再操作浏览器逐项比对。不要另做风格和结构不同的 HTML 原型或用提案图替代原版证据。
- 原因：本次自制原型既不像 NocoBase，也不像用户已有页面，增加了无用产物并偏离还原目标；用户明确否定该做法。
- 适用场景：已有参考软件、源码和可运行页面的 UI/UX 复刻及区块封装；实现截图必须来自本项目真实页面，未实现或未实测明确标记。
- 表单覆盖补充：用户追问指出子区块与动态表单不能只作为新增按钮里的几张截图带过。清单需单列表单区块自身的创建、数据上下文、字段增减、布局/拖拽、局部配置、动作及重开保存；区分“表单类型”和“作为子区块放置”，避免遗漏表单独立入口。

- 运行贡献与创建入口分离（2026-11-10 11）：可挂载或可导入的前端贡献不应自动成为可创建区块；组件、模板与直接创建用途必须按底座协议声明分流。用户确认日历插件只提供组件和模板，不直接注册可创建区块；原因是复用全量运行目录让组件与模板错误出现在区块管理和创建菜单。适用于插件注册、资源目录和后台管理入口。
