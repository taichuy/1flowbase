- 规则：插件前端限定为插件内固定后台设置页文件，由原生代码声明路由并注册到现有 UI 模板体系，不扩展为前端热更新平台。
- 最新纠正：首次启用及升级插件触发默认模板覆盖更新；用户已修改的模板也覆盖，提前明确告知覆盖触发条件，由用户自行保存和处理自定义代码。不做旧默认/当前内容/新默认比较，不做自动合并。此决定替代此前三方比较和保留用户修改的方案。
- 边界：覆盖插件提供的 UI 模板，不据此重置用户填写的业务配置或凭据。普通重启和同版本重新启用不应被扩大为新的覆盖触发点；具体失败重试与首次应用记录在实施契约中闭合。
- 原因：用户明确认为内容比较增加了不必要的复杂度，接受可预期触发点上的覆盖，并要求清楚告知用户。
- 适用：后续插件计划、Wiki、设置页注册和升级实现；当前仅对齐方案，不能宣称行为已落地。
