- 规则：用户指定监控插件的侧边栏分组名称为“负载监控”；此次不扩大为修改页面标题、MCP 实例名称或采集行为。
- 原因：用户对截图中“算负载监控”名称提出明确更名。
- 适用场景：当前商业 compute-monitor 插件的设置导航；后续调整须保留用户先本地审阅、再允许线上推送的边界。
