规则：公开 Wiki、文档、Issue 与截图应隐藏用户个人部署域名；截图用不可辨认的遮罩，示例文字可使用官网 https://1flowbase.taichuy.com/，明确实际部署需替换示例。
原因：用户于 2026-10-06 明确要求个人公网域名打码，避免公开教程与修复记录暴露私人部署入口。
适用场景：发布或更新公开教程、截图、验收记录和 Issue。真实验证仍可在本地私有证据使用实际地址，但不要把个人入口传播到新的公开内容。
