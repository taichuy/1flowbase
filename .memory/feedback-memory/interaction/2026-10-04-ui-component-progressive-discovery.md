## 规则

本次需求聚焦现有组件 UI 方案与两层渐进式接口；已导入组件自动进入分类与组件检索。demo 代码是后续内容来源，不把制作 demo 页面当成本轮目标。

## 原因

用户明确纠正了改造对象，目的是让 Agent 先发现分类，再搜索分类中的组件并按需获取代码。

## 适用场景

本次组件 UI 检索方案、接口设计及后续实现。
