# 计价配置问题的边界

- 规则：用户明确允许同一模型存在多条用户配置；限制只针对空白应用初始化 / 拉取内置价格，同一模型不能导入两条官方标准计价。“固定字段 + 规则”的具体层级：id、厂商、模型、四项默认价格及其他固定字段直接位于配置顶层，不能仍包在 rules 数组内；rules 数组只承载特殊条件与价格覆盖，不再嵌套另一份 rating_policy 或复制无条件默认 rates。不可扩大成全表模型唯一约束。
- 原因：用户询问的是计价数据结构，不只是列表展示或版本状态；此前回答误判成新旧版本展示不清，随后又误推断默认价格也应放进 JSON，均已被用户纠正。
- 适用：当前模型计价配置与 Docker 空白应用初始化讨论。用户已确认第四项是缓存写入，四项为输入、输出、缓存命中、缓存写入。
