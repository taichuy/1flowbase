subject: 助手模型菜单刷新与失效偏好的处理
feedback_category: interaction
decision_policy: direct_reference
---
规则：AI 助手缓存用户模型选择习惯，但打开模型选择菜单时应重新获取对应应用已发布版本的模型列表。保存的选择仍存在则保留；不存在则按最新列表顺序选第一个可用模型并保存，不仅提示不可用要求用户重新选择。可用的推理强度习惯保留，否则使用替换模型支持的默认值。
原因：用户于 2026-09-28 明确纠正，只提示不可用却未在打开菜单时刷新，会让最新配置和失效判断都不可靠，并增加手动操作。
适用场景：嵌入式 AI 助手模型选择菜单和对应设置刷新；发布版本仍为运行真值，不读取编排草稿替代发布配置。
