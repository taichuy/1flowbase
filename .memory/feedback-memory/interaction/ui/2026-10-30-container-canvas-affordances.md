- 规则：循环/迭代在同一无限画布内编辑时，选择节点已表达当前对象，不再显示“返回主画布/当前位于容器”这类暗示另一张画布的浮条。
- 规则：复刻连接器时核对真实缩放后的屏幕大小、加号可见性和命中区域，不能仅以存在一个连接点或逻辑CSS尺寸就判定贴合参考图。
- 原因：用户指出首版多余浮条和过小输出连接器均与提供的Dify参考图不符；应保留清楚直接的点击新增/拖线入口。
- 适用：本项目同屏嵌套容器和其普通节点连接器；不外推为所有页面都取消导航或任意增大全部按钮。
