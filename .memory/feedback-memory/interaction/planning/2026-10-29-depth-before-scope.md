# 规则

用户要求把方案做深时，先回答四件事：该领域专业实践还会补上哪些未被显式要求的工作、应读取哪些原始一手材料、具体方法与工具、除了用户与 AI 判断之外的独立正确性证据；再据此重写方案。

# 原因

在 2026-10-29 循环/迭代节点方案中，用户明确要求“做得更深，而不是做得更大”。增加功能、泛化引擎或拉长计划不能代替精确定义语义、检查保证成立的前提、寻找反例与建立可复跑证据。

# 适用场景

复杂运行时、状态、恢复、并发等能力的方案深化。保留已确认产品范围；将数学规范、有限模型检查、真实实现验证与完整程序证明区分，未经执行不声称已证明或已验收。
