---
title: SSH 插件按受管子进程与声明贡献定界
date: 2026-10-10 22
feedback_category: interaction
decision_policy: direct_reference
---

规则：用户明确 SSH 插件通过子进程和公开协议声明能力，由基座注册并执行治理；不能仅因需要数据表、设置页、接口和 MCP 注册就要求 HostExtension。角色与接口授权沿用现有体系。

原因：贡献内容与执行方式、宿主信任边界是不同维度。当前注册契约若只开放给 Host，应评估给受管插件开放声明入口，而不是迫使业务插件参与宿主内部实现。

适用：SSH 商业插件方案，以及类似声明 UI、数据、操作的受管业务插件。用户尚未批准具体底座改造方案；本记录不授权放开认证 factory、原生进程内执行或任意 SQL。
