## 规则

诊断已注册节点在导入时被误判缺失时，核对注册定义及所有消费者的真实数据来源，修复方向优先收敛到同一后端能力真值的投影。不要把追加重复白名单当作已满足统一注册目标，也不要把落实既定统一注册原则笼统描述成额外的激进重构。

## 原因

独立维护节点清单会再次漂移：节点能编辑、能执行，却被导入器误判未知。用户明确指出导入检测应与注册节点保持一致。

## 适用场景

工作流节点目录、编译支持、导入导出与插件能力发现的一致性诊断。统一真值仍应区分应用类型、运行可用性、编辑器展示和内部结构节点；前端渲染器注册与后端执行资格并非同一职责。
