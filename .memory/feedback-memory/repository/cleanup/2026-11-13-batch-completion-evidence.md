- 规则：用户要求每批100条直到完成时，批大小只是单批约束；工作流必须跟踪后台真实进度，全部完成才返回成功，失败明确暴露。验收区分已提交、已删除和全部完成。
- 原因：用户在定时清理试运行后追问是否只删100条；现场发现虽已删除558条，后台另一个任务失败，而原工作流已在入队时成功，容易误判效果。
- 适用场景：持久化异步任务、定时分批删除和相同的后台完成语义；磁盘文件大小与逻辑删除效果分别取证，不用批次参数或提交回执证明完成。
