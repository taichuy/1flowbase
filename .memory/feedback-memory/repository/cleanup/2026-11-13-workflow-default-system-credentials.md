- 规则：用户要求创建工作流即自带创建者与执行者两种只读系统凭证变量，归截图系统变量sys.*；两个变量同时存在，任意节点可引用对应凭证并按对应主体权限调用接口。不是普通env配置，也不是持久化conversation变量。
- 原因：用户明确纠正了AI“定时运行固定使用创建者、手动运行固定使用执行者”的解释；不能把两个可选变量改成按触发类型二选一。
- 适用场景：工作流默认变量、节点接口认证、身份与权限讨论。变量名称和底层发行/恢复/脱敏机制由当前契约与实现核实，不把记忆当已实现能力。
- 同轮边界：定时清理必须复用页面正式删除接口，不在工作流SQL中直接写删除队列或业务表；统一三类应用的日志删除规则，保留30天、固定100条分批并等待全部完成。
