- 规则：用户期望系统自带、插件和自定义事件的定义目录持久化到数据库并统一查询；系统与插件定义由启动、安装或升级生命周期新增和更新，不以接口请求时拼接运行时声明替代持久化。用户纠正的是定义目录的数据来源，不应自行扩展为队列或运行中事件实例全部持久化。
- 原因：用户在事件目录时间列调试时指出，系统和插件事件显示无时间属于当前实现缺口；“当前未持久化”不等于“无法持久化”，不能把现状当作合理产品边界。
- 适用场景：事件目录、更新时间、定义注册与插件同步设计。该记录保存用户目标；具体表结构、停用卸载策略和迁移方案仍需按当前源码与本轮确认收敛，不自动授权修改历史数据。
